## English

The first macOS release of Android Mirror: a native SwiftUI window for viewing and controlling Android phones without an installed companion app or root.

### Download and install

Download **AndroidMirror-0.1.0-macos-universal.dmg**, open it, and drag **AndroidMirror.app** into **Applications**. Requires **macOS 14+**, supports **Apple Silicon and Intel**, and includes ADB. `SHA256SUMS.txt` provides the download checksum.

**Signing:** this build is locally ad-hoc signed and **not Apple-notarized**. macOS may block the initial launch. Review the publisher/source and use the per-app **Open Anyway** option in **System Settings → Privacy & Security** if you choose to allow it. Signature integrity checks are not Apple notarization.

### Included

- QR-code and six-digit Wireless debugging pairing, plus USB connections.
- Device selection, saved devices, renaming and removal.
- Mouse/keyboard control, text clipboard sync, and direct Unicode entry into supported editable fields without changing the clipboard.
- View-only mode, phone/Mac audio selection, proportional window resizing, screenshots and rotation.
- Restorable keep-awake behavior and optional physical-screen-off while controlling.
- Phone PIN/password entry, protected Keychain storage, Touch ID/Mac-login authentication and configurable autofill validity. Each connection still requires an explicit click.
- Complete English/Simplified Chinese UI and help, following the system's preferred app language.
- Capability-based Android checks, IPv6 endpoints, primary-display geometry and conservative keyguard parsing.
- English-first bilingual README, development documentation, reusable build/DMG scripts and MIT license.

### Compatibility and validation

USB mirroring requires Android 5.0+. Wireless debugging pairing and Mac audio require Android 11+; Android 11 audio capture must start while unlocked. Direct Unicode entry requires Android 7.0+, main user 0 and an accessible editable field. Saved-password protection requires Secure Enclave support on the Mac.

Vendor security policies may reject remote input/unlocking; protected screens or audio may be unavailable. Patterns and non-ASCII lock passwords should be entered on the phone. Password submission is never retried automatically. No file drag-and-drop, multitouch or phone-notification forwarding is included.

Validation: 62 Swift tests passed, one optional device test skipped, seven pure Java text checks passed; both architectures compiled, DMG checksum and nested signatures verified, and the packaged app launched. English and Chinese layouts were inspected. Intel execution and every Android vendor/lock-screen variation have not been verified on physical hardware.

## 简体中文

安卓镜像首个 macOS 发行版：原生 SwiftUI 手机窗口，支持投屏和操控，无需在手机安装配套应用或 root。

### 下载与安装

下载 **AndroidMirror-0.1.0-macos-universal.dmg**，打开后将 **AndroidMirror.app** 拖入「应用程序」。需要 **macOS 14+**，支持 **Apple Silicon 和 Intel**，已包含 ADB。下载校验值见 `SHA256SUMS.txt`。

**签名状态：**此构建使用本地 ad-hoc 签名，**未经过 Apple 公证**。macOS 可能阻止首次打开；确认发布者与源码后，可按系统提示在「系统设置 → 隐私与安全性」中对该应用选择「仍要打开」。签名完整性验证不代表 Apple 公证。

### 包含功能

- 二维码、六位配对码无线配对，以及 USB 连接。
- 顶部设备选择、保存设备、重命名与删除。
- 鼠标与键盘操控、文字剪贴板同步、向支持的输入框直接提交 Unicode，与剪贴板分离。
- 仅投屏、手机或电脑声音、窗口等比例缩放、截图和旋转。
- 可恢复的保持唤醒、操控时可选关闭手机实体屏幕。
- 手机 PIN / 密码输入、受保护的钥匙串保存、触控 ID / Mac 登录密码验证及可设置的自动填充有效期，每次仍需点击连接。
- 全英文与简体中文界面、帮助指南，默认跟随系统应用语言。
- 基于能力的安卓适配、IPv6 地址、主屏幕坐标和保守的锁屏状态判断。
- 英文在前的双语 README、开发文档、可复用构建及 DMG 脚本、MIT 许可证。

### 兼容性与验证

USB 镜像需要 Android 5.0+；无线调试配对和电脑声音需要 Android 11+，Android 11 捕获声音时需先解锁。直接输入 Unicode 需要 Android 7.0+、主用户 user 0 和支持编辑接口的输入框。保存密码需要 Mac 支持安全隔区。

厂商安全策略可能拒绝远程输入或解锁，受保护画面和声音可能无法镜像。图案及非 ASCII 锁屏密码请在手机输入。密码不会自动重复提交。此版本未包含文件拖放、多点触控及手机通知转发。

已验证：62 项 Swift 测试通过、1 项可选实机检查跳过、7 项纯 Java 文本检查通过；双架构编译、DMG 校验和嵌套签名完整性通过，包内应用可启动，并检查了英文和中文排版。未在 Intel 实机及所有安卓厂商、锁屏变体上逐一验证。
