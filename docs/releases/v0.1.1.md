## English

Android Mirror 0.1.1 improves picture quality, USB entry and viewing without unlocking.

### Changes

- Added Standard, High Quality and Maximum Quality settings independently of resolution. High Quality defaults to 16 Mbps at 1920; original resolution supports up to 32 Mbps. Picture changes restart the media connection.
- Preserve full/video-range decoding, propagate source color information and refresh the display description when image color attachments change. Added synthetic gradient regression fixtures.
- An authorized USB phone opens the password-entry page automatically, marked **USB Connection**, whether it has been saved or removed from the device list. Saved passwords do not replace this USB input form.
- Prefer authorized USB before connecting; preserve active transports and defer newly attached USB phones until the current session ends. Repeated discovery respects manual device selection.
- Added **Direct Mirroring** to the window and Phone menus. It starts a read-only session without Mac authentication, saved-password access, password submission or lock-screen navigation. It does not wake the phone or change its sleep timeout. The received screen remains visible while locked; Android-protected content may still be black.
- Updated English/Simplified Chinese UI, help and README.

### Download and validation

Download **AndroidMirror-0.1.1-macos-universal.dmg**, open it and drag **AndroidMirror.app** into **Applications**. Requires **macOS 14+**; includes ADB and supports **Apple Silicon and Intel**. Verify the download with `SHA256SUMS.txt`.

This build is **ad-hoc signed and not Apple-notarized**. macOS may require the app-specific Open Anyway option in System Settings → Privacy & Security after you review the source/publisher.

Validation: 74 Swift tests passed, one optional device test skipped, and seven pure Java checks passed. Both architectures compiled; the DMG, bundle signatures and packaged version were checked. The macOS app launched and the Direct Mirroring menu label was inspected. USB attachment policies were tested with synthetic transports; every Android vendor and Intel execution have not been verified on physical hardware.

Higher bit rates reduce compression artifacts but do not add HDR or extra bit depth to the current 8-bit H.264 stream. USB mirroring requires Android 5.0+; wireless debugging pairing and Mac audio require Android 11+. Android security policies may restrict input, unlocking, captured screens or sound.

## 简体中文

安卓镜像 0.1.1 改进画质、USB 连接入口，并新增直接镜像。

### 更新内容

- 画质与分辨率分开设置，新增标准、高画质、最高画质。默认高画质在 1920 分辨率下使用 16 Mbps，原分辨率最高支持 32 Mbps。更改画面设置后会重新建立媒体连接。
- 正确保留全范围、有限范围解码及源视频的色彩信息，在图像色彩信息变化时更新显示描述；新增程序生成的渐变回归样本。
- 已授权的 USB 手机被识别后，自动进入密码输入页，显示「USB 连接」。不要求先添加设备，从列表删除过的 USB 手机也能识别；已有保存密码时仍显示 USB 输入框。
- 连接前优先使用已授权 USB，镜像过程中保留当前连接，新插入的 USB 手机待当前连接结束后选中；重复刷新不会覆盖手动选择。
- 三点菜单与「手机」菜单新增「直接镜像」。直接开始仅显示画面的连接，不进行 Mac 验证、不读取或提交密码，也不上滑或点击锁屏。不会唤醒手机或修改熄屏时间；锁定时显示手机返回的画面，安卓受保护内容仍可能是黑色。
- 同步更新中英文界面、帮助与 README。

### 下载与验证

下载 **AndroidMirror-0.1.1-macos-universal.dmg**，打开后将 **AndroidMirror.app** 拖入「应用程序」。需要 **macOS 14+**，支持 **Apple Silicon 和 Intel**，已包含 ADB。下载校验值见 `SHA256SUMS.txt`。

此构建使用 **ad-hoc 本地签名，未经过 Apple 公证**。确认源码与发布者后，macOS 可能需要在「系统设置 → 隐私与安全性」中对该应用选择「仍要打开」。

已验证：74 项 Swift 测试通过、1 项可选实机检查跳过、7 项纯 Java 检查通过；双架构编译、DMG、签名完整性及包内版本检查通过；应用可启动，已检查「直接镜像」菜单名称。USB 插拔策略使用模拟连接测试，未逐一验证所有安卓厂商及 Intel 实机运行。

提高码率可减少压缩色块，但不会为当前 8 位 H.264 视频增加 HDR 或位深。USB 镜像需要 Android 5.0+，无线调试配对与电脑声音需要 Android 11+。安卓安全策略可能限制输入、解锁、画面或声音捕获。
