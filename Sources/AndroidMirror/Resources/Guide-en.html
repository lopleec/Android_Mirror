Your Android phone, on your Mac.

Android Mirror connects through ADB. No root access or installed phone app is needed. Select a device at the top of the window and find controls in the … menu.

Connect wirelessly

  1. Connect the phone and Mac to the same Wi-Fi. Enable Wireless debugging in the phone's Developer options (Android 11+). Allow local network access if macOS asks.
  2. Click Connect Phone. For QR pairing, use Wireless debugging → Pair device with QR code on the phone, rather than the camera app. A QR code expires after two minutes.
  3. Alternatively, select Pairing Code and enter the IP address, pairing port and six-digit code from the phone's pairing dialog.
  4. The connection port is discovered after pairing. If it cannot be found, enter the connection port from the main Wireless debugging page. It differs from the pairing port.

Manual host fields accept IPv4, hostnames or IPv6. Guest Wi-Fi and client isolation can block connection or discovery. If ADB is missing, open Settings → Devices → Advanced Connection Settings, download Google Platform-Tools, then select its adb executable with Choose ADB….

Connect by USB

Enable USB debugging, connect a data-capable cable and allow this Mac's debugging request on the phone. Select the phone and click Connect. USB mirroring supports Android 5.0+.

Control and type

Click the mirror to focus input. Drag to swipe, hold to long-press, scroll to browse and right-click to go back. Mac input methods can send committed Unicode text directly to ordinary editable fields on Android 7.0+ in the main user profile. Custom or protected editors may reject direct text; use the phone keyboard or explicit paste. Typing does not silently update the clipboard.

View, screen and sound

… → Interaction → View Only leaves operation on the phone and disables Mac input and clipboard sync. Settings → General contains resolution, screen-power, keep-awake, clipboard and window options. Keep-awake changes the screen timeout without repeated wake commands; disconnecting restores it. Automatic physical-screen-off starts after unlocking.

Choose Phone Speaker or Mac Speaker for sound. Mac audio requires Android 11+; Android 11 must be unlocked when capture starts. Protected apps may prohibit video or audio capture. If video stutters, try Smooth · 1280p, better Wi-Fi or USB.

Unlock and save a password

Enter the phone PIN/password and click Unlock or Connect and Unlock. The app wakes the screen, swipes up and waits for the password prompt before sending the password once. It never retries a password automatically. If a vendor restricts remote unlock, unlock on the phone.

Settings → Password manages password saving, the US physical-keyboard or compatibility input method, and Mac authentication validity. Digits and printable ASCII letters/symbols are supported; patterns and other lock passwords should be entered on the phone.

Saved passwords are encrypted in this Mac's Keychain with Secure Enclave-backed protection. Autofill requires Touch ID or your current Mac account's login password. Within the chosen validity period (10 minutes by default), further Mac authentication is unnecessary, but you still click Connect each time. Locking/sleeping the Mac or quitting clears that cache. Showing, changing and deleting passwords always requires fresh authentication. Revealed/edited content hides after 30 seconds, on focus loss or when leaving the password settings.

Manage devices and language

Rename and remove saved phones in Settings → Devices. Removal deletes this app's record and saved password; remove ADB pairing separately in the phone's Wireless debugging settings if needed.

The interface follows the system's preferred app language, supporting English and Simplified Chinese with English fallback.
